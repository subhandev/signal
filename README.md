# SIGNAL

> Turn any topic into structured intelligence.

SIGNAL is an autonomous research agent that searches the web, scrapes relevant pages, synthesises findings using AI, and returns a structured intelligence report — with live streaming progress updates as it works.

![SIGNAL Demo](./docs/demo.gif)

**Live Demo:** [signal.vercel.app](https://signal.vercel.app)

---

## What it does

Give SIGNAL a topic, company, or question. It autonomously:

1. **Searches** the web using Tavily for relevant sources
2. **Scrapes** and reads the most relevant pages
3. **Synthesises** findings using GPT-4o
4. **Returns** a structured report — executive summary, key findings, detailed analysis, market context, risks, and cited sources

All in real time. Watch the agent think, search, and build the report live.

---

## Features

- **Autonomous agent loop** — LangChain AgentExecutor orchestrates multi-step research without human intervention
- **Live streaming** — Server-Sent Events stream agent progress to the frontend in real time
- **Three research modes** — Quick (~15s), Standard (~45s), Deep (~2min)
- **Structured reports** — Consistent JSON output with confidence scoring
- **Shareable reports** — Every report gets a permanent URL
- **Public gallery** — Browse reports generated by SIGNAL
- **PDF export** — Download any report as a formatted PDF
- **Rate limited** — 10 research jobs per hour per IP

## How the agent works

```
User submits query
      ↓
POST /api/research → job created in DB → job_id returned
      ↓
GET /api/research/{id}/stream → SSE connection opened
      ↓
LangChain AgentExecutor starts
      ↓
┌─────────────────────────────────┐
│  GPT-4o decides next action     │
│         ↓                       │
│  Calls web_search (Tavily)      │  → SSE: "search" event
│         ↓                       │
│  Reads results                  │
│         ↓                       │
│  Calls scrape_page (httpx)      │  → SSE: "scrape" event
│         ↓                       │
│  Calls summarise_content        │  → SSE: "thinking" event
│         ↓                       │
│  GPT-4o reflects, decides again │
│         ↓                       │
│  Repeats until confident        │
└─────────────────────────────────┘
      ↓
Outputs structured JSON report
      ↓
Saved to Postgres
      ↓
SSE: "complete" event with full report → Frontend renders
```

## Quick Start

### Prerequisites

- Python 3.11+
- Node.js 18+
- OpenAI API key
- Tavily API key (free at [tavily.com](https://tavily.com))

### 1. Clone the repo

```bash
git clone https://github.com/subhandev/signal.git
cd signal
```

### 2. Backend setup

```bash
cd backend
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
# Edit .env — add your API keys
uvicorn app.main:app --reload --port 8000
```

### 3. Frontend setup

```bash
cd frontend
npm install
cp .env.example .env.local
# Edit .env.local — set NEXT_PUBLIC_API_URL=http://localhost:8000
npm run dev
```

### 4. Open the app

Visit [http://localhost:3000](http://localhost:3000)

## Deploying the backend (Railway)

1. Create a Railway service from this repo and set **Root Directory** to `backend`.
2. In **Settings → Config-as-code**, set the config file path to `/backend/railway.toml` if Railway does not pick it up automatically.
3. Add the backend environment variables (see above). Use Neon’s `postgresql+asyncpg://…` URL for `DATABASE_URL`.
4. Set `ALLOWED_ORIGINS` to your Vercel URL (e.g. `https://signal.vercel.app`).
5. Redeploy. Start command (from `backend/`): `uvicorn app.main:app --host 0.0.0.0 --port $PORT`.

Point the Vercel frontend’s `NEXT_PUBLIC_API_URL` at your Railway service URL.

### Start research

```bash
curl -X POST https://your-backend.up.railway.app/api/research \
  -H "Content-Type: application/json" \
  -d '{"query": "Anthropic", "mode": "standard"}'

# Returns:
{
  "job_id": "uuid",
  "status": "pending",
  "query": "Anthropic",
  "mode": "standard",
  "created_at": "2025-01-17T..."
}
```

### Stream results

```bash
curl -N https://your-backend.up.railway.app/api/research/{job_id}/stream

# Streams SSE events:
data: {"type": "search", "message": "Searching: Anthropic AI"}
data: {"type": "scrape", "message": "Reading: anthropic.com"}
data: {"type": "thinking", "message": "Analysing..."}
data: {"type": "complete", "message": "Research complete", "report": {...}}
```
